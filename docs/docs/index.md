# Louder!

The extremely interactive fiction engine. Designed for nonsense and whimsy.

# Parts

This project is in development, and will come in 3 parts.

 - [Editor](./editor/). The software provided to create branching dialogue trees.
 - [Engine](./engine/). The library provided to interpret branching dialogue trees and
 turn them into gameplay.
 - [Example](./examples/). Starter projects to guide you through using the tool and inspire
 project ideas.
 - [API](./rustdoc/louder_rust/). API reference for the base engine.
