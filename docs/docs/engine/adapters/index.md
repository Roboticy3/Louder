# Adapters

The [engine](../index.md) functionality is exposed through a variety of
"adapters": language wrappers and compilation systems around the engine that
allow it to be used in different contexts.

# Rust Library
The louder_rust module is the source code of the engine, and exposes many useful
data types. The docstrings in this code also serve as the authoritative
documentation on the function of the engine.

# Python Bindings
Python bindings via [PYO3](https://github.com/PyO3/pyo3).

# Godot Bindings
Godot bindings via [Gdrust](godot-rust.github.io).
