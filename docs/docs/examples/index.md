# Examples

These programs give examples of how to integrate the [engine](/engine/) into
different contexts and allow users to see and interact with conversations made
in the [editor](/editor/). A good way to start will be to pick an example to
use as a template for your own project.

 - [text based crpg](./tbcrpg.md)
 - [cursed godot + renpy client](./cgprpc.md)
