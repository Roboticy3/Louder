When nodes reference other nodes, they should do so in the export menu. Indicate when you are doing this to the user so they can set up the node connections manually according to the scene hierarchy.

When writing user-facing documentation under `docs/`, write from the user's perspective. Describe what the user sees and does, not the underlying implementation. Avoid referencing class names, scene node names, Godot engine internals, or code architecture (e.g. don't mention `GraphEdit`, `CustomGraphHub`, `SpinBox`, `CodeEdit`, script names, scene tree order, signal connections, or serialization class names). Use plain terms like "node", "text field", "number spinner", "dropdown", "checkbox", etc. Prefer longer single documents over many short subpages -- they render better in the readthedocs theme.
